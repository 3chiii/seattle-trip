      날짜예보최고/최저옷차림

      옷차림 원칙

      • 레이어 3장 — 긴팔 티 + 얇은 플리스(또는 가디건) + 후드 있는 방수 재킷. 시애틀 사람들은 우산보다 후드를 씁니다.
      • 신발은 방수 운동화 하나로 통일. 젖은 낙엽·보도가 미끄럽습니다. 레이니어 가는 날만 등산화가 있으면 좋아요.
      • 레이니어(해발 1,650m)는 시애틀보다 8~10°C 낮고 바람 — 체감 0°C. 경량 패딩 + 비니 + 장갑. 첫눈이 올 수도 있는 시기.
      • 페리는 바다 위라 체감이 3~4°C 낮아요. 실내 객실이 있지만 갑판에 나갈 때 목도리·비니.
      • 낮엔 15~19°C까지 올라가서 벗고 입기 쉬운 구성이 핵심. 얇은 옷 여러 장이 두꺼운 옷 한 장보다 낫습니다.

      가져갈 것

      옷

      • 방수 후드 재킷 (필수)
      • 얇은 플리스·가디건 2
      • 긴팔 티 4~5, 반팔 1~2
      • 바지 3 (청바지 1, 속건 1)
      • 방수 운동화 + 편한 실내용
      • 비니·장갑·얇은 목도리 (레이니어·바다용)
      • 얇은 경량 패딩 (레이니어용, 저녁용)
